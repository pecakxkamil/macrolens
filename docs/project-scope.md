# Project Scope

MacroLens is planned as a U.S. macroeconomic data analytics platform.

The current scope is limited to the initial project scaffold and documentation placeholders. The first functional milestone will focus on a Labor Market module using PAYEMS, UNRATE, and ICSA.

Out of scope for the initial scaffold:

- Data ingestion
- Database models
- API endpoints
- Analytics implementation
- Frontend implementation
- AI implementation
